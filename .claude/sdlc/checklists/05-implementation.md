# レビューチェックリスト: 05-implementation 実装

1. 単体テストが全件成功（Green）している（`test-run-green.md` の証跡）。機械チェック（`checks.md`）の MUST が通っている
2. 単体テスト（工程 4 の成果物）を変更していない（ゲートのハッシュで機械的にも確認される）
3. すべての DD に対応するコードがあり、trace: DD-xxx がある（trace check）
4. DD に無い機能を実装していない（過剰実装）
5. lint が通り、カバレッジが閾値以上（project.yaml の coverage_threshold）
6. Refactor 後もテストが成功し、重複・不要コードが無い
7. エラー処理・入力検証・リソース解放が DD の例外定義どおり
