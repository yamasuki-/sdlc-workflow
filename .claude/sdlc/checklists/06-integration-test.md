# レビューチェックリスト: 06-integration-test 結合テスト

1. すべての IT にテストコードがあり、trace: IT-xxx がある（trace check）
2. テストが IT 仕様の手順・期待結果を忠実に実装している（期待値を実装に合わせていない）
3. テストダブルの使用範囲が IT 仕様どおりで、検証対象の結合を置き換えていない（DB・外部システムは可能な限り実物かそれに近いもの）
4. IF の正常系に加えてエラー伝播・タイムアウト・トランザクション境界を検証している。N+1 等の性能上の問題が無い
5. モジュール間のデータの流れ（基本設計のデータフロー）が網羅されている
6. 実行結果（test-results.md）が記録され、失敗はすべてトリアージされ、製品・テスト起因は不具合票（DEF）になっている
7. src_dir を変更していない（修正は /defect 経由）
