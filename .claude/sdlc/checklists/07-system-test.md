# レビューチェックリスト: 07-system-test システム／受入テスト

1. すべての AT にテストコード（または手動手順と結果記録）があり、trace: AT-xxx がある（要求の 100% がカバーされている）
2a. テストが業務シナリオ（利用者の一連の操作）として成立している。手動試験は第三者が再現できる手順になっている
2b. 環境依存（時刻・乱数・外部サービス・データ）への対処が明記されている
2. テストが AT 仕様どおりで、期待値を実装に合わせていない
3. NFR の測定結果が基準値と比較されている
4. 要件カバレッジ（trace-matrix.md）で REQ → SR → AT → テストコードが全件つながっている
5. 失敗はすべて不具合票になり、未クローズの不具合が報告されている
6. カバレッジ計測値が閾値以上
