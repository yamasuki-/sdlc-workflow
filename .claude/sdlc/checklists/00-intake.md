# レビューチェックリスト: 00-intake 取り込み

1. 入力ドキュメントのすべてのシート / 見出し / スライドが取り込まれている（件数を原本と照合）
2. 各 SRC に出典（形式別の単位）と確信度がある
3. 表形式の要求が行単位に展開され、列名と値の対応が正しい（結合セル展開の範囲を含む）
4. 「要画像読取」の図がすべて読み取られ、読取結果と確信度が記入されている
5. 変更履歴（挿入・削除）・非表示シート・ノートの扱いが注記されている
6. 確信度「低」の箇所が index.md に列挙され、要求整理・分析工程の質問に回す準備ができている
7. 原文の意味を変える要約・補完をしていない（中間形式は原文に忠実）
