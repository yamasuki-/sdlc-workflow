# レビューチェックリスト: 03-basic-design 基本設計

1. すべての SR が BD / IF に展開されている（trace check）
2. モジュールの責務が単一で、依存方向が循環していない
3. IF のシグネチャ・データ形式・エラーが曖昧なく定義されている
4. NFR（性能・セキュリティ等）を満たす設計上の手当てがある
5. すべての IF に結合テスト仕様（IT）があり、正常・異常（エラー伝播）を含む
6. 技術選択が project.yaml（言語・フレームワーク）と整合している
7. モジュールの配置（src_dir 配下）が決まっており、並行実装できる粒度に分かれている
