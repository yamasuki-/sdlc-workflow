# レビューチェックリスト: 01-requirements 要求整理・分析

1. すべての SRC が REQ に反映されている、または「対象外: 理由」が書かれている（trace check）
2. 1 REQ = 1 要求になっている（複合要求が分割されている）
3. 要求の言い換えで意味が変わっていない（出典と突き合わせ）
4. 曖昧（数量・条件・主語の欠落）・矛盾（要求間・資料間）・欠落（異常系・権限・データ量・運用）が issues.md に挙がっている
5. 確信度「低」の SRC が質問または仮定として扱われている
6. 質問は具体的で、回答が無い場合の仮定と影響が書かれている
7. 機能 / 非機能 / 制約の分類と優先度が妥当
